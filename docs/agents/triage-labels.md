# Etiquetas de triagem

As skills falam em cinco papéis canônicos de triagem. Este arquivo liga cada papel à etiqueta usada no issue tracker deste repositório.

| Etiqueta em mattpocock/skills | Etiqueta neste tracker | Significado                                   |
| ----------------------------- | ---------------------- | --------------------------------------------- |
| `needs-triage`                | `needs-triage`         | O mantenedor precisa avaliar a issue          |
| `needs-info`                  | `needs-info`           | Aguarda mais informação de quem abriu         |
| `ready-for-agent`             | `ready-for-agent`      | Especificada por inteiro, pronta para agente  |
| `ready-for-human`             | `ready-for-human`      | Precisa de implementação humana               |
| `wontfix`                     | `wontfix`              | Não será feita                                |

Quando uma skill cita um papel (por exemplo, "apply the AFK-ready triage label"), use a etiqueta correspondente desta tabela.

Edite a coluna "Etiqueta neste tracker" para acompanhar o vocabulário que o repositório de fato usa.
